# INTEGRA — Создаём сайты, которые работают

Современный многостраничный сайт веб-студии INTEGRA в стиле Apple с продвинутыми анимациями.

## Структура проекта

```
INTEGRA/
├── index.html          # Главная страница
├── portfolio.html      # Портфолио проектов
├── services.html       # Услуги
├── pricing.html        # Тарифы
├── about.html          # О компании
├── contact.html        # Контакты и форма заявки
├── main.js             # JavaScript (GSAP анимации)
├── style.css           # Дизайн-система
├── animations.txt      # Справочник по анимациям
├── images/             # Изображения проектов
└── README.md
```

## Страницы

| Страница | Описание |
|----------|----------|
| **Главная** | Hero с canvas-частицами, About, Clients, Marquee, Portfolio, Services, Team, Process, Pricing, Testimonial, FAQ, Contact |
| **Портфолио** | Полная галерея проектов с фильтрацией |
| **Услуги** | Детальное описание услуг с ценами |
| **Тарифы** | 3 тарифных плана с таблицей сравнения |
| **О нас** | История компании, ценности, таймлайн |
| **Контакты** | Форма заявки, способы связи |

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — кастомные свойства, Grid, Flexbox, анимации
- **JavaScript** — vanilla JS, GSAP 3.12.5
- **GSAP** — ScrollTrigger, MotionPathPlugin

## Анимации

- Canvas particles (60 частиц с линиями)
- Typing effect (печатающийся текст)
- Split-text (посимвольное появление)
- 3D tilt на карточках
- Magnetic buttons (притяжение к курсору)
- Cursor trail (шлейф из точек)
- Glow cards (светящаяся обводка)
- Text scramble (шифрование текста)
- Scroll blur reveal (появление из размытия)
- Marquee (бегущая строка)
- Horizontal scroll portfolio
- Circuit SVG animation (draw + motion path)
- Animated gradient mesh
- Parallax layers
- Section morphing (clip-path)
- Animated stats (прогресс-бары)
- Scroll snap
- Counter animation с суффиксами

## Функционал

- Dark/Light тема с localStorage
- Мобильное меню с анимацией
- Валидация формы с ошибками
- Success particles при отправке
- Scroll progress bar
- Active nav link tracking
- Smooth scroll
- Адаптивный дизайн (1024/768/480px)

## Запуск

Откройте `index.html` в браузере. Никакой сборки не требуется.
